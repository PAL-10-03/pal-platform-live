PAL Integration Release — 2026-11-06

IMPLEMENTED IN THIS PACKAGE:

- Gmail OAuth callback: https://palbiz.app/gmail/callback
- One-time hashed OAuth state stored in Supabase; encrypted Gmail refresh token
  stored in Supabase; sender identity must match PAL_EMAIL_FROM.

  recipient-specific customer + PAL owner copies, dispatch ledger.
